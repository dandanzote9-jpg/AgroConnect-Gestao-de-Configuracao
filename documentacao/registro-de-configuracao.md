## 2. Objetivo

Organizar, controlar e manter os artefatos do projeto AgroConnect por meio de um sistema de gerenciamento de configuração, utilizando Git e GitHub para armazenar arquivos, registrar modificações, controlar versões e permitir a rastreabilidade das alterações realizadas.

## 3. Escopo do Gerenciamento de Configuração

O gerenciamento de configuração deste projeto contempla:

- Criação e organização do repositório remoto.
- Obtenção dos arquivos por meio da clonagem do repositório.
- Identificação e organização dos artefatos.
- Modificação e criação de arquivos.
- Controle das alterações realizadas.
- Registro das versões do projeto.
- Publicação das atualizações no GitHub.
- Verificação da integridade dos arquivos publicados.

## 6. Controle de Versões

O projeto utiliza o Git para controlar as versões dos artefatos e o GitHub como repositório remoto.

A branch principal utilizada é `main`.

Cada alteração deverá ser registrada por meio de commits, contendo mensagens que identifiquem as modificações realizadas.

O histórico de versões permitirá acompanhar a evolução dos arquivos e recuperar versões anteriores quando necessário.

## 8. Procedimento de Controle de Alterações

Para manter a organização e a rastreabilidade do projeto, será adotado o seguinte procedimento:

1. Identificar o arquivo que precisa ser alterado.
2. Realizar a alteração no ambiente local.
3. Verificar as alterações utilizando `git status`.
4. Adicionar os arquivos modificados utilizando `git add`.
5. Registrar as alterações utilizando `git commit`.
6. Publicar as atualizações utilizando `git push`.
7. Acessar o repositório remoto no GitHub e verificar se os arquivos modificados ou criados foram publicados corretamente, conferindo o conteúdo e o histórico de commits.
